## Live findings observed before changes

1. **Robots points at the wrong host.** `/robots.txt` named `https://rtsolutions.dev/sitemap.xml`, while the verified active Render service is `https://rtsolutions-site.onrender.com`. It also disallowed `/_next/`, which can prevent crawlers from fetching rendering assets.
2. **Sitemap contains fragment URLs.** `/sitemap.xml` listed the home page plus six `#section` URLs. Those fragments do not represent separately crawlable pages.
3. **Canonical link was absent.** The live page had Open Graph and Twitter image URLs but no `rel="canonical"`.
4. **Unverified commercial claims were rendered as facts.** Examples included an `80%+` test-coverage target, Lighthouse CI gates, a five-year maintenance minimum, WCAG AA compliance, automated axe CI, manual screen-reader QA, principal-level involvement, direct Slack/email access, and a 30-day support window. These are not substantiated by the repository or owner-supplied facts.
5. **Footer contained dead anchors.** “Case Studies” and “Creative Directions” were rendered as disabled links with `href="#"`; they still had link destinations and could jump the page.
6. **404 contact CTA stayed on the 404 route.** `href="#contact"` resolved against the not-found route instead of returning to the home page.
7. **Contact form semantics were incomplete.** Visible required markers and custom validation existed, but the controls lacked native `required` semantics. The mailto fallback exposed internal option keys such as `website`, `25-50`, and `1-3` instead of the selected human-readable labels.
8. **Draft lifetime copy was misleading.** The placeholder warning suggested a visitor could return later with the same entries, but form state is in-memory only and is cleared on refresh/navigation.

## Changes on this branch

- Generate `robots.txt` from Next.js metadata using the configured site origin; remove the stale static file and stop disallowing Next.js assets.
- Reduce the sitemap to the one real, indexable page and remove fragment URLs.
- Add a canonical URL using the existing metadata base.
- Change the unconfigured URL fallback to the verified primary Render service; the environment variable still overrides it for a verified custom domain or deployment.
- Remove footer links for unpublished case studies and creative directions rather than leaving dead anchors.
- Route the 404 contact action to `/#contact`.
- Add native required semantics and autocomplete to the contact fields while retaining custom validation through `noValidate`.
- Convert project, budget, and timeline option keys into human-readable labels in the mailto draft.
- Clarify that placeholder-mode drafts exist only in the currently open page.
- Replace unsupported service-level claims and guaranteed timelines with scope-aware, evidence-neutral copy.
- Add Playwright regression tests for SEO, robots/sitemap, dead links, 404 navigation, contact semantics, and mobile menu behavior.
- Extend the CI pull-request trigger to include the active Claude build branch so this separate PR can receive the existing checks.
