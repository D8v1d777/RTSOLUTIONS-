# RTSOLUTIONS

An independent software and digital product studio. We build custom websites, web applications, and desktop applications. Our point of difference is creative frontend craft: gathering messy ideas and shaping them into expressive, useful digital experiences built to last.

## Project status

This repository is prepared for the full website implementation by Claude Code. The product brief, design direction, acceptance criteria, and execution rules are committed and should be read before implementation.

## Product

- **Websites:** original, high-craft brand and marketing experiences.
- **Web applications:** custom interactive products, dashboards, and SaaS interfaces.
- **Desktop applications:** purpose-built software for focused workflows.

## Visual direction

The intended art direction is cinematic and editorial: near-black surfaces, deep crimson and scarlet light, a luminous jellyfish as the signature art object, oversized typography, asymmetric composition, and restrained glass/metal details. The implementation must be an original RTSOLUTIONS identity—not a copy of another agency's branding or layout.

## Planned technical direction

The initial implementation direction is Next.js App Router, React, TypeScript, Tailwind CSS 4, Three.js / React Three Fiber, Motion, and Lucide. Claude Code must verify compatibility against current official documentation before locking the final implementation.

## Business details

Official domain, email, phone, social accounts, location, pricing, client projects, and testimonials have not been supplied. Do not invent them. Any temporary values must be clearly marked as placeholders and centralized for later replacement.

## Verification status

No production build, browser QA, accessibility audit, performance audit, or deployment is claimed at this stage. These checks are required before the website is considered complete.
